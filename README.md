# 🛒 MERN E-Commerce Project

A full-stack E-Commerce web application built using the MERN stack with a modern shopping experience, authentication, product management, cart, orders, reviews, PayPal sandbox payments, search, and an admin dashboard.

## 🚀 Features

### 👤 Authentication
- User registration and login
- Protected routes
- Admin authentication
- Role-based access control
- Secure logout

### 🛍️ Shopping
- Browse products
- Product categories
- Brand filtering
- Product search
- Product details
- Featured products
- Responsive shopping interface

### 🛒 Cart
- Add products to cart
- Update product quantities
- Remove products from cart
- Stock validation
- Real-time cart item count

### ⭐ Product Reviews
- Add product reviews
- 1–5 star ratings
- Display average rating
- Display total reviews
- Prevent duplicate reviews from the same user

### 📦 Orders
- Checkout system
- Address management
- Order history
- Order details
- Order status tracking

### 💳 Payments
- PayPal Sandbox integration
- Payment capture
- Payment status tracking
- COD support

### 👨‍💼 Admin Dashboard
- Admin dashboard
- Product management
- Order management
- Feature/banner management
- Add, edit and delete homepage features
- Feature image uploads

### 📱 Responsive Design
- Mobile-friendly UI
- Tablet support
- Desktop support
- Responsive navigation
- Responsive product grids

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Redux Toolkit
- Tailwind CSS
- Axios
- Lucide React
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Payment
- PayPal Sandbox

- Git
